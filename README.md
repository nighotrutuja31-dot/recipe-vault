# 🍴 RecipeVault

RecipeVault is a modern and responsive personal recipe book developed using HTML5, CSS3 and JavaScript.

It allows users to create, view, edit, delete and organize recipes using categories.

## ✨ Features

- Add recipes
- Edit existing recipes
- Delete recipes
- Unique recipe IDs
- Category assignment
- Category filtering
- Search recipes
- Sort recipes
- Recipe detail view
- Favorite recipes
- Cooking time
- Difficulty levels
- Servings information
- Dark mode
- Responsive design
- Toast notifications
- Delete confirmation
- localStorage persistence
- Modern responsive UI

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- Google Fonts
